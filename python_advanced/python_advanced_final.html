1.3 格式化輸出 (f-string)

🎯 學完這節，你會用 f-string 控制數字小數位數、補零、對齊，輸出更專業的格式。

在字串引號前加上 f 或 F，即可在字串中使用 {} 嵌入變數或運算式。冒號 : 後面接的是格式規則，讓你控制數字或文字的顯示方式。

📐 語法結構
f"{ 值 : 填充字元 對齊方式 寬度 . 精度 型別 }"
● 值：變數或數字 ● 填充字元：如 0 或空格 ● 對齊：^ < > ● 寬度：總字元數 ● 精度：小數位數 ● 型別：f / d / s
（以上選項皆為選填，依需求組合使用）
# 定義變數
name = "Alice"
score = 95.123
# 使用 f-string 格式化
msg = f"Hi, {name}. Score: {score:.2f}"
print(msg)
Hi, Alice. Score: 95.12
🔢 小數點位數 :.2f — 常用於金額、成績、科學數據
語法說明：. 精度 f
.2 = 顯示 2 位小數 f = float 浮點數
print(f"{95.123:.0f}") # 95（無小數）
print(f"{95.123:.2f}") # 95.12
print(f"{95.123:.4f}") # 95.1230

2.4 短路求值 (Short-circuit Evaluation)

Python 在計算 and / or 時，只要已經能確定結果，就不會繼續往後算。這就像電路短路一樣，電流不再繼續流下去。
💬 白話說：Python 會偷懶，確定答案後就不繼續算了——and 遇到 False 直接停、or 遇到 True 直接停。

or 運算 (A or B)

只要 A 是 True，結果一定是 True，B 不需要再看。

or
B: Check()
因為 A 是 True，結果已確定為 True。
B 不會被執行 (短路)

and 運算 (A and B)

只要 A 是 False，結果一定是 False，B 不需要再看。

and
B: Check()
因為 A 是 False，結果已確定為 False。
B 不會被執行 (短路)

6.2 淺拷貝 vs 深拷貝

淺拷貝像是複印一本書的目錄，內容頁還是共用的——改了原本的內容，複印本也會跟著變。深拷貝像是把整本書連內容都重新印一份，兩本完全獨立，互不影響。
copy() 是淺拷貝（只複製第一層），deepcopy() 是深拷貝（全部都重新複製）。

* 深拷貝需要 `import copy` 模組。

真 Python 對應寫法：
shallow = original.copy()  # 或 original[:]
deep = copy.deepcopy(original)
⚠️ 常見錯誤：以為 b = a 或 b = a.copy() 就完全獨立——前者連外層都共用，後者內層仍共用。改內層元素前，先想清楚要淺還是深！

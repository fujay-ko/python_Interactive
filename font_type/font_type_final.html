1. 英文大小寫 (Case Sensitivity)

英文有大小寫之分，但中文沒有。點擊下方按鈕或輸入文字體驗差異。

2. 全形與半形 (Width Comparison)

觀察背景格線：半形字佔半格或一格，全形字佔兩格（正方形）。試著輸入：123, abc, ( )

⚡ 3. 程式碼字形規則

⚠️ 在程式碼中，幾乎所有字元都應該使用半形！

類別 說明 應使用半形（範例）
英文字母 關鍵字、變數、字串內容 print name Hello a~z A~Z
數字 數值、索引、編號 0~9   x = 10   list[0]
運算子 算術、比較、指定 + − * / = == != < >
括號 函式呼叫、區塊、陣列 ( ) [ ] { }
引號 字串邊界 " " ' '
標點符號 語法分隔、逗點、冒號 , ; : . # @ % _
斜線 路徑、跳脫、註解 / \

✅ 字串內容中的中文可以使用全形標點，如 print("你好，世界！")

❌ 但引號、括號、逗號、冒號等語法本身一律必須半形

💡 記憶口訣： 寫程式用半形，字串中文可全形
